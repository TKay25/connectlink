What this is

When per-branch stock was introduced, a startup routine gave this branch a stock row for every product in the shared catalogue — seeded from the company total. Any item added at another branch therefore appeared here carrying that branch's own figure, and this branch's till stopped hiding it. The routine is fixed; the rows it already wrote are not removed by themselves.

A row is listed below only when this branch has no receipt, no cost layer and no sale behind it, while another branch genuinely holds the item. Nothing else is ever touched. Removed rows are copied to a backup table first, and the catalogue totals are recalculated afterwards.
